# salud-en-primera
El objetivo de este proyecto es implementar una aplicación web que permita la gestión de un sistema que nos ayude a analizar los hábitos de alimentación, de actividad física y de sueño del alumnado, profesorado y comunidad educativa participante.

Con ello se persigue la digitalización y organización de los datos que actualmente se obtienen en formato papel y su posterior análisis del conjunto de resultados y búsqueda de posibles correlaciones reflexionando críticamente sobre la interpretación de los datos, sus limitaciones y posibles sesgos. Además, como objetivo se plantea la presentación de dichos resultados para su análisis.
